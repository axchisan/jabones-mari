# Material fuente

Lo que no se publica pero conviene conservar.

- **`fotos-del-producto/`** — las fotos caseras originales de cada jabón, comprimidas.
  Son la referencia real de forma, color e inclusiones: si hay que volver a generar
  o retocar imágenes con IA, se parte de aquí (ver `docs/05-prompts-gemini.md`).
- **`referencias-folletos/`** — los folletos de otro emprendimiento que sirvieron de
  referencia de estructura para las piezas publicitarias.

Las imágenes que sí usa la web están en `web/public/`. Las de marca, en `brand/`.
